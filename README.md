# 🏠 Predictive Insight Engine – House Price Prediction

A Machine Learning project that predicts house prices using property features and regression algorithms.

## 📌 Project Overview

The **Predictive Insight Engine** analyzes real estate data to understand the factors affecting house prices and build predictive regression models.

## 📂 Dataset

- **Dataset:** `RealEstate_HousePrice_Dataset_4200.csv`
- **Total Records:** 4,200
- **Target Variable:** `house_price_inr`
- **Features:** Area, bedrooms, bathrooms, location score, house age, distance from city, lot size, garage, pool, and renovation details.

## 🛠️ Technologies Used

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn
- SciPy
- Statsmodels
- Jupyter Notebook

## ⚙️ Project Workflow

1. **Data Loading & Inspection** – Load and understand the dataset.
2. **Data Preprocessing** – Check missing values, duplicates, and select features.
3. **Exploratory Data Analysis (EDA)** – Analyze distributions, relationships, and correlations.
4. **Data Visualization** – Create histograms, scatter plots, and correlation heatmaps.
5. **Model Building** – Implement regression algorithms.
6. **Model Evaluation** – Compare model performance using evaluation metrics.

## 🤖 Machine Learning Algorithms

- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Batch Gradient Descent
- Stochastic Gradient Descent
- Mini-Batch Gradient Descent
